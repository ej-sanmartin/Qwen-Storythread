Effective LoRA update RMS

Update size: how large each projection's low-rank change is, as |scale| · ||A B||F / √(in · out). It does not say how much the update changes behavior; that is a separate question for ablation.

How to read this (axes, colors, caveats)
  • One bar (or cell) is one LoRA-adapted weight matrix in one transformer block.
  • Left to right is which projection, labeled with the exact names used in the checkpoint keys. See What do these labels mean? below the chart.
  • Front to back is the block index (adapted blocks only).
  • Height and color are the effective LoRA update RMS: the typical size of the change LoRA adds to each weight in that matrix. Taller means the adapter moved that matrix more.
  • Recent vs earlier view: a bar above the floor means the recent arm's update is larger, below the floor means the earlier arm's is larger. Height is the gap as a percent of the earlier arm. The step selector shows how the gap and the sizes change over training.
  • A blank spot means that block has no adapter on that projection (the model mixes attention types).
  • This is size, not behavior. A large update does not show that the model's replies changed; only evaluation or ablation can.
    What do these labels mean?

    Labels are the projection names found in this checkpoint's tensor paths, and values are measured from its tensors. This architecture is not in the glossary, so no descriptions or groups are shown.

    Qwen's projections are not LoRA's factors. in_proj_a and in_proj_b are names of Qwen's projections, weight matrices in the base model. They are distinct from the LoRA A and B factors (lora_a, lora_b): every adapted projection gets its own pair of those, and the chart measures the size of their product.

    Height and color show the size of the learned correction. A taller in_proj_a bar alone cannot tell us whether the model retains more context or remembers a story event better; that takes evaluation or ablation.

    The groups and descriptions below are written for Qwen3.5-4B, which mixes Gated DeltaNet layers with full-attention layers. They are shown only because this checkpoint was recognized as Qwen3.5.

    Transformer layers (blocks)

    A block is one transformer layer, numbered from 0; the model has 32 and each feeds the next. MLX-LM adds LoRA only to the last num_layers blocks, so this lists just the blocks on the chart's front-to-back axis. Every other block keeps the base model's weights. In Qwen3.5-4B every fourth block is full attention and the rest are Gated DeltaNet. The layer type is read from the projection names found in each block.
